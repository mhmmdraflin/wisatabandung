# Wisata Bandung

Aplikasi Flutter untuk menampilkan destinasi wisata di kota Bandung.

## Deskripsi
Proyek ini adalah aplikasi mobile berbasis Flutter yang menyajikan informasi tempat-tempat menarik untuk dikunjungi di Bandung. Aplikasi ini dibuat sebagai media pembelajaran dan portofolio dalam pengembangan aplikasi mobile dengan Flutter.

## Fitur
- Menampilkan daftar tempat wisata di Bandung
- Halaman detail untuk setiap tempat wisata (deskripsi, foto, fasilitas)

## Cara Menjalankan
1. Pastikan Flutter SDK sudah terinstal di perangkat Anda.
2. Clone repositori ini: `git clone https://github.com/mhmmdraflin/wisatabandung.git`
3. Masuk ke direktori proyek.
4. Instal dependensi: `flutter pub get`
5. Jalankan aplikasi: `flutter run`

## Teknologi yang Digunakan
- Flutter
- Dart
