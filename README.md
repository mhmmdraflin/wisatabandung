## 📝 Deskripsi

**Wisata Bandung** adalah aplikasi mobile yang dirancang untuk membantu pengguna menemukan dan menjelajahi berbagai tempat wisata menarik, budaya, dan pesona alam di kota Bandung.

Aplikasi ini dibangun menggunakan **Flutter**, menghadirkan antarmuka yang modern, responsif, serta pengalaman navigasi yang mulus di berbagai perangkat Android maupun iOS.

---

## ✨ Fitur

- 🏛️ **Daftar Destinasi Wisata**  
  Menampilkan berbagai pilihan tempat wisata populer di Bandung.

- 📝 **Detail Informasi**  
  Menyajikan informasi lengkap terkait deskripsi wisata, lokasi, dan fasilitas.

- 🖼️ **Galeri Interaktif**  
  Melihat kumpulan foto menarik dari setiap tempat wisata.

- ❤️ **Favorite / Bookmark** (Opsional)  
  Menyimpan destinasi wisata favorit untuk diakses dengan mudah nanti.

## 🚀 Cara Menjalankan

### 1. Prasyarat

* Flutter SDK
* Android Studio atau Visual Studio Code
* Emulator atau perangkat fisik (Android/iOS)

### 2. Clone Repository

```bash
git clone https://github.com/mhmmdraflin/wisatabandung.git
cd wisatabandung
```

### 3. Install Dependency

```bash
flutter pub get
```

### 4. Jalankan Aplikasi

```bash
flutter run
```
